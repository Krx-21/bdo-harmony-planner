# Harmony Draught Planner (web)

BDO [Party] Harmony Draught calculator — Vercel + Discord login (PKCE) + Upstash cloud sync.

- `index.html` — the whole app (generated by `src/build.py` + `src/build_web.py`; icons + recipe data embedded)
- `api/` — zero-dependency Vercel serverless functions

## Setup (2 ขั้น ไม่ต้องคัดลอก secret ใดๆ)

เว็บใช้งานแบบ guest ได้ทันที (เก็บข้อมูลในเครื่อง) — ทำ 2 ขั้นนี้เพื่อเปิดล็อกอิน Discord + ซิงก์ข้ามอุปกรณ์:

### 1) Discord Developer Portal → แอปของคุณ → หน้า OAuth2
- ช่อง **Redirects** กด Add แล้วใส่ (ต้องตรงเป๊ะ):
  `https://bdo-harmony-planner-v2.vercel.app/api/callback`
- เปิดสวิตช์ **Public Client** = ON  ← สำคัญ! ระบบใช้ PKCE จึงไม่ต้องใช้ Client Secret เลย
- กด **Save Changes**

> ทางเลือก: ถ้าไม่อยากเปิด Public Client ให้ตั้ง env `DISCORD_CLIENT_SECRET` (และ `DISCORD_CLIENT_ID`) ใน Vercel แทน — โค้ดรองรับทั้งสองแบบ

### 2) Vercel → Project → Storage
- **Create Database** → เลือก **Upstash (Redis)** แผนฟรี → **Connect** เข้าโปรเจกต์นี้
- Vercel จะใส่ env `KV_REST_API_URL` / `KV_REST_API_TOKEN` ให้อัตโนมัติ
- ไปแท็บ **Deployments** → จุดสามจุดของอันล่าสุด → **Redeploy** (ให้ env มีผล)

เสร็จ: ปุ่ม "ล็อกอิน Discord" มุมขวาบนใช้ได้ ข้อมูล (เป้าหมาย/คลัง/ความคืบหน้า) ซิงก์ตามบัญชีอัตโนมัติ (ไอคอน ☁ = ซิงก์แล้ว)

## Notes / Security
- Discord Client ID ฝังในโค้ด (เป็นค่า public โดยธรรมชาติ ปรากฏใน URL อยู่แล้ว); ไม่มี secret ใดๆ ใน repo
- Session = HMAC-signed cookie อายุ 30 วัน; secret สุ่มอัตโนมัติเก็บใน Redis (`hdp:cfg:session_secret`) หรือ override ด้วย env `SESSION_SECRET`
- เก็บเฉพาะ Discord id / ชื่อ / รูป; ข้อมูลผู้ใช้เป็น JSON ต่อ id (`hdp:state:<id>`) จำกัด 400KB
- Recipe data scraped from bdocodex.com (2026-08-19)
