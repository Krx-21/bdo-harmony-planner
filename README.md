# Harmony Draught Planner (web)

BDO [Party] Harmony Draught calculator — deployed on Vercel with Discord login + cloud sync.

- `index.html` — the whole app (generated by `src/build.py` + `src/build_web.py` in the main project folder; icons + recipe data embedded)
- `api/` — zero-dependency Vercel serverless functions (Discord OAuth + per-user state in Upstash Redis)

## Setup (one time, ~5 นาที)

เว็บใช้งานได้ทันทีแบบ guest (เก็บข้อมูลในเครื่อง) — ทำ 2 ขั้นนี้เพื่อเปิดล็อกอิน Discord + ซิงก์ข้ามอุปกรณ์:

### 1) Discord OAuth
1. ไป https://discord.com/developers/applications → **New Application** ตั้งชื่ออะไรก็ได้ (เช่น Harmony Planner)
2. เมนู **OAuth2** → คัดลอก **Client ID** และกด **Reset Secret** เพื่อได้ **Client Secret**
3. ในหน้าเดียวกัน ช่อง **Redirects** กด Add:
   `https://<โดเมนโปรเจกต์>.vercel.app/api/callback`
4. ใน Vercel → Project → **Settings → Environment Variables** เพิ่ม:
   - `DISCORD_CLIENT_ID` = Client ID
   - `DISCORD_CLIENT_SECRET` = Client Secret
   - (แนะนำ) `SESSION_SECRET` = ข้อความสุ่มยาวๆ อะไรก็ได้

### 2) ฐานข้อมูล (ซิงก์ข้ามเครื่อง)
1. Vercel → Project → **Storage** → **Create Database** → เลือก **Upstash (Redis)** แผนฟรี → **Connect** เข้าโปรเจกต์
2. Vercel จะใส่ env `KV_REST_API_URL` / `KV_REST_API_TOKEN` (หรือ `UPSTASH_REDIS_REST_URL/TOKEN`) ให้อัตโนมัติ — โค้ดรองรับทั้งสองชื่อ

### 3) Redeploy
Deployments → เมนูจุดสามจุดของ deployment ล่าสุด → **Redeploy** (ให้ env ใหม่มีผล)

เสร็จแล้ว: ปุ่ม "ล็อกอิน Discord" มุมขวาบนจะพาไป Discord, ข้อมูล (เป้าหมาย/คลัง/ความคืบหน้า) ซิงก์ตามบัญชีอัตโนมัติ (ไอคอน ☁ = ซิงก์แล้ว)

## Notes
- ไม่มี dependency ใดๆ — deploy ตรงจาก repo, ไม่มี build step
- Session = HMAC-signed cookie อายุ 30 วัน; เก็บเฉพาะ Discord id/ชื่อ/รูป
- ข้อมูลผู้ใช้เก็บเป็น JSON ต่อ Discord id เดียว (`hdp:state:<id>`), จำกัด 400KB
- Recipe data scraped from bdocodex.com (2026-08-19)
